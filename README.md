# Skill2Cash

Transforme clairement les compétences en revenus.

App web pour découvrir des **opportunités alignées avec tes skills** (freelance, affiliation, produits digitaux, local) avec plans d’action et hooks de monétisation.

## Lancer en local

```bash
npm install
npm run dev
```

## Gagner de l’argent avec ce projet

1. **Affiliation** — remplace les URLs dans `src/data/opportunities.ts` par tes liens trackés.
2. **Alertes Premium** — les emails sont stockés en `localStorage` (`s2c_leads`) ; branche un backend (Formspree, Supabase, Beehiiv) puis facture 29–99 MAD/mois.
3. **Leads / sponsors** — monétise la liste ou la newsletter.

## Stack

- Vite + React + TypeScript
- Framer Motion
- CSS custom (pas de framework UI)
